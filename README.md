# 작업지시 — Claude 공통 오케스트레이션 지침 (마스터)

모든 Claude 프로젝트에서 공통으로 쓰는 최상위 작업지침의 원본 폴더입니다.

## 새 프로젝트에 적용하는 법

1. `CLAUDE.md`를 대상 프로젝트 루트에 복사합니다.
2. (권장) `docs/` 폴더도 함께 복사합니다 — 없어도 Claude가 첫 세션에 자동 생성합니다.
3. Claude Code에서 프로젝트를 열고 작업을 요청하면, Claude가 프로젝트를 파악해 `docs/`를 채우고 오케스트레이터로 동작합니다.

## 무엇이 들어있나

- **CLAUDE.md** — 방법론. 역할 정의, 토큰 최적화 7원칙, 8단계 작업 루프, 난이도(L0~L3)-모델 배정표와 배정 하한, 위험 체크리스트, 병렬성 판정 기준, 위임 프로토콜(경량 경로·검증 포함), 문서 체계와 지식 축적 원칙.
- **docs/** — 프로젝트 고유 정보가 채워지는 템플릿. 이 폴더에서는 비어있는 것이 정상입니다.
  - `00~04` — 상태 문서: 목표(01), 구조(02), 위험(03), 결정(04)과 진입점 색인(00).
  - `specs/` — 기능명세 층: 목표 → 기능(F-###) → 티켓(T-###) 계층의 중간층.
  - `tasks/` — 작업 층: 현황판(BACKLOG)과 자기완결 티켓.
  - `experience/` — 경험 축적 층: 위임 대장·배정 보정(AGENTS), 오류 사례집(ERRORS), 노하우(LESSONS).

## 설계 의도

- CLAUDE.md는 프로젝트와 무관한 "방법"만 담고, 프로젝트 고유 정보는 전부 `docs/`로 분리 → **파일 하나만 복사해도 어디서든 재사용** 가능.
- 모든 문서 머리에 3줄 헤더(목적 / 읽는 시점 / 갱신 시점) → **새 창에서 열어도 각 문서의 용도가 바로 파악**됨.
- 세션 시작 시 읽는 문서를 INDEX → (필요 시) BACKLOG로 제한 → 세션마다 낭비되는 토큰 최소화.
- 경험은 `experience/`에 원시 기록(대장 1줄, 사례 15줄)으로 쌓이고, **같은 패턴이 2회 확인되면 규약·배정 보정 규칙·노하우로 승격** → 프로젝트가 진행될수록 배정 정확도와 작업 품질이 실측 기반으로 개선됨. 프로젝트 무관 교훈([공통] 태그)은 이 마스터 폴더로 환류.
