# briefs — 브리프(B)·설명(G)·워크시트(W) 양식
> 목적: 사용자와 지휘자 사이의 번역 문서. B는 사용자의 요구를 지휘자용으로(소통자), G는 지휘자의 함축된 내용을 사용자용으로(소통자), W는 사용자만 할 수 있는 작업의 실행 워크시트(요청자). CLAUDE.md §7.4.
> 읽는 시점: 지휘자는 명세를 쓰기 전에 B를. 사용자는 설명·브리핑을 받을 때 G를, 직접 작업을 할 때 W를.
> 갱신 시점: 새 요구가 들어올 때(B), 설명·브리핑이 필요할 때(G), 사용자 직접 작업이 생기거나 워크시트 수정 요청이 올 때(W, 판 번호 상승). 완료된 B·G는 고치지 않고 새 번호로 쓴다.
